# 图式（schema）

图式 = 可复用、可推理的心智模型（日志中也写作「图示」）。每条图式足够小、足够精确，才能被识别和复用。
字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 认知过滤器 🔄

- **目的**：当认知信息过多、需要判断「值不值得看」时。
- **实体**：认知负担检测、认知密度检测、认知工具、过滤器。
- **手段-目的**：认知负担/密度检测不合格 → 打回不处理；合格 → 进入下一步处理。
- **约束**：适用于批量认知输入；检测工具本身还在融合中。
- **行动**：想提高专注力 → 做认知负担工具；想判断信息有效度 → 融合认知密度检测。

## 2. 降维加工

- **目的**：面对混沌的原始想法，需要分门别类、提取结构时。
- **实体**：原始想法、结构化分析（事实/感受/行动）、干净结构。
- **手段-目的**：原始信息结构化分析 → 分门别类 → 得到干净的降维结果。
- **约束**：对大批量想法才有用；单个想法不需要降维。
- **行动**：想从混沌中找到结构 → 加工、分类、降维。

## 3. 同步思考（思考云）

- **目的**：构建与人类同步思考的系统时。
- **实体**：思考云、人类认知与观察、AI 处理。
- **手段-目的**：人类提供认知与观察 → AI 结构化处理 → 与人类同步的思考结果。
- **约束**：人类负责提供认知与观察；AI 负责处理。思考侧重认知结构，区别于沟通。
- **行动**：想持续思考 → 建立连续思考的信息结构（批处理与流处理无区别）。

## 4. 档案交付

- **目的**：从日志提炼认知、交付成果时。
- **实体**：认知状态、思考状态、档案、归档。
- **手段-目的**：交付认知状态与思考状态 → 形成认知工程档案 → 界限明确（留档 vs 归档）。
- **约束**：档案只交付「理解到什么程度」；思考模式、方法是更高层次内容。
- **行动**：想交付认知成果 → 摘出图示与情境；想法、意图类内容可清空。

## 5. insight 优先

- **目的**：在 insight 与 intention 之间选择工作对象时。
- **实体**：insight（思考的核心结果）、intention（意图）。
- **手段-目的**：思考云与 insight 对应度高 → 以 insight 为核心工作。
- **约束**：intention 仍重要，但不作为思考云的主要对应物。
- **行动**：想推进思考 → 围绕 insight 工作。

## 6. 对抗性协同进化

- **目的**：系统与认知共同演进、需要互相校正时。
- **实体**：需求、举证/质疑、系统、认知。
- **手段-目的**：明确需求 → 互相举证（互举）→ 系统与认知共同收敛。
- **约束**：需要结果导向、需求明确；先有目标，再决定思考什么、认知什么。
- **行动**：想让体系收敛 → 明确需求并互相质疑。

## 7. 清楚/不清楚评估

- **目的**：评估某一认知是否还需要继续思考时。
- **实体**：清楚的部分、不清楚的部分。
- **手段-目的**：清楚 → 不再想；不清楚 → 继续思考。
- **约束**：适用于认知自我评估，不适用于知识掌握度考核。
- **行动**：想判断思考焦点 → 区分清楚与不清楚。

## 8. 内外边界

- **目的**：划分内部想法与对外表达时。
- **实体**：核心想法（私有）、市场观察（对外）、领域（向内）、业务（向外）。
- **手段-目的**：核心想法私有化 → 内外边界清晰 → 领域向内、业务向外。
- **约束**：适用于个人/组织表达边界，不适用于产品开放策略。
- **行动**：想让边界清晰 → 私有化核心想法，对外写市场观察。

## 9. 两阶段推进

- **目的**：体系从扩张期转入深耕期时。
- **实体**：第一阶段（铺摊子）、第二阶段（领域内集中+跨域关联）。
- **手段-目的**：摊子铺开、积累足够认知 → 进入第二阶段集中信息并与其它领域关联。
- **约束**：第二阶段需要第一阶段积累；尚未进入的领域不适用。
- **行动**：想升级体系 → 先铺开，再集中关联。

## 10. 日志弹性归属

- **目的**：日记/日志记在哪个领域不确定时。
- **实体**：日记、领域日志、上下文（资产轴）。
- **手段-目的**：日记记在哪没关系 → 想到相关话题再整合 → 增加上下文；原始日记是最丰富的资源。
- **约束**：领域交叉性大、边界弹性，不纠结归属；不是所有日志都对思考有用。
- **行动**：想丰富上下文 → 跨日志整合而非新建分类。

## 11. 认知负担双刃

- **目的**：推行降低认知负担的措施时。
- **实体**：认知负担、降低负担的过程、新负担。
- **手段-目的**：降低认知负担方向正确 → 但过程本身引入新负担 → 需要低成本跨过。
- **约束**：适用于个人与团队；规模化的核心难题。
- **行动**：想帮助团队规模化减少负担 → 把操作部分标准化教程化（生产实习）。

## 12. 脚手架复用

- **目的**：旧结构/旧格式需要更替时。
- **实体**：旧结构（脚手架）、新结构。
- **手段-目的**：旧结构完成了历史作用 → 可丢弃重建 → 新结构重新开始。
- **约束**：旧内容仍有参考价值时作为脚手架；不必为兼容旧格式而保留。
- **行动**：想重新开始 → 保留旧结构为脚手架，直接重建。
