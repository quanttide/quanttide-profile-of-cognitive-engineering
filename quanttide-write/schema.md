# 图式（schema）· 写作

图式 = 可复用、可推理的心智模型。字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 叙事工程

- **目的**：撰写文档、精修产品时。
- **实体**：文档、故事、功能列表、AI 叙事能力。
- **手段-目的**：文档讲故事 → 克服 AI 无叙事能力/习惯 → 用户理解。
- **约束**：几乎所有文档都要讲故事，不是列功能。
- **行动**：用故事承载逻辑，而非罗列功能。

## 2. 三段修改循环

- **目的**：提升任何产出质量时。
- **实体**：大改、小改、精修、智能体任务。
- **手段-目的**：大改（推翻重来）→ 小改 → 精修 → 质量提升。
- **约束**：对几乎所有智能体任务通用；大改或推翻重来的习惯需要在所有领域工作建立。
- **行动**：先大胆推翻，再逐步精修。
