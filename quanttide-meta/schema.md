# 图式（schema）· 元认知

图式 = 可复用、可推理的心智模型。字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 目标先行

- **目的**：确定思考方向、认知对象时。
- **实体**：目标、思考、认知。
- **手段-目的**：先有目标 → 知道思考什么、认知什么 → 认知收敛。
- **约束**：需要结果导向、需求明确。
- **行动**：先明确整体目标，再展开认知。

## 2. 认知收敛

- **目的**：评估系统演化状态时。
- **实体**：认知、系统状态、更高层次的结构。
- **手段-目的**：系统状态向高层次收敛 → 看到更完整的结构 → 接近最终目标。
- **约束**：需要持续积累与输出。
- **行动**：保持输出日志与想法，与系统同步演化。

## 3. 脚手架重建

- **目的**：旧结构/旧格式需要更替时。
- **实体**：旧结构（脚手架）、新结构。
- **手段-目的**：旧结构完成历史作用 → 作为脚手架丢弃重建 → 新结构重新开始。
- **约束**：不必为兼容旧格式而保留；旧内容仍有参考价值时作为脚手架。
- **行动**：直接重建，不被旧结构束缚。

## 4. 对抗性协同进化

- **目的**：系统与认知共同演进时。
- **实体**：需求、举证/质疑（互举）、系统、认知。
- **手段-目的**：需求明确 → 互相举证 → 系统与认知共同收敛。
- **约束**：需要结果导向；先有目标再决定思考什么。
- **行动**：明确需求并互相质疑。
