# 量潮战略认知档案

战略的通用方法论是入口寻找：找到让整个体系方法论保持一致的战略框架。招聘是甲方的模式入口——用招聘的过剩荣誉资源给课堂导流；给数据、云导流需要找到类似的过剩资源。开源核心但边际的资产（已有项目）：开源后通过渠道推一遍，打开客户思路——无论客户自己做还是找我们做都有收益；最终都是通过分享数据获得规模效应。战略管理创造全新的东西；经济建模解释已有的思路。聚焦初级劳动力市场，高级劳动力市场不熟悉，不做。

当前的关键动作：为数据、云寻找类似招聘的过剩资源入口；推动联盟机制——市场状况、自身情况、合作伙伴已发展到临界点，当前主要加强整合。入口模式能否复制到其他业务、联盟机制（实训基地的关键资源是合作企业）能否落地，均待验证。
