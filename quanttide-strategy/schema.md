# 图式（schema）· 战略

图式 = 可复用、可推理的心智模型。字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 入口寻找 🔄

- **目的**：为新业务/产品导流时。
- **实体**：招聘入口、过剩资源、其他业务。
- **手段-目的**：找到过剩资源 → 成为甲方模式入口 → 为其他业务导流。
- **约束**：需要前期积累发展到临界点才出现；不是所有业务都有现成入口。
- **行动**：从招聘复制方法论，寻找其他业务的类似入口。

## 2. 开源导流

- **目的**：打开客户思路、获取潜在收益时。
- **实体**：已有项目（核心但边际的资产）、开源、渠道、数据云。
- **手段-目的**：开源边际资产 → 渠道推一遍 → 客户思路打开 → 无论自己做还是找我们做都有收益。
- **约束**：只开源边际资产，核心资产保留私有。
- **行动**：开源已有项目，通过渠道推送。

## 3. 规模效应

- **目的**：放大收益时。
- **实体**：数据、分享、规模。
- **手段-目的**：分享数据 → 获得规模效应。
- **约束**：所有路径最终都归结于分享数据。
- **行动**：以分享数据为核心组织战略。

## 4. 实训基地

- **目的**：放大人才培养优势时。
- **实体**：实训基地、合作企业、候选人。
- **手段-目的**：合作企业愿意接收（真的在招聘）→ 实训基地成立 → 人才培养规模化。
- **约束**：关键资源是合作企业；在不缺人、明确大部分人不适合时模式才可能成立。
- **行动**：依靠合作伙伴推荐的合适渠道。
