# 量潮文档（quanttide-docs）认知档案

文档工程关心文档阅读本身的负担：通过对文档格式做定量分析，以人类阅读体验反向评估内容质量，让 AI 参与写作后依然可读、可维护。

文档工程与叙事工程的分工是：叙事工程关心故事内核与叙事方向，文档工程关心阅读负担等基础指标，两层评估互不替代。「文档格式」章程经论证归属文档工程。

文档之间的连接对应业务关系的显影，因此文档默认保持树状，网状连接仅在业务明确规定时建立；链接按所连接文档的层级分为文章、书籍、图书馆三层，链接混乱的根源是把不同层级混在一起处理。文档云的治理能力以此为据：管理全局结构、预警链接混乱之处、以关系可视化图支撑治理决策。

规则类文档按稳定性分层沉淀：流程与工具无关，进手册；操作与工具绑定，进教程；质量检查标准最稳定，进章程。规则类制品由工作日志逐步总结沉淀，工作语境是它们的上游。
