# 图式

图式是可复用、可推理的心智模型。它有两类形态：概念结构型，定义实体与层级，效力来自概念本身清晰；经验归纳型，从多个情境中提炼，须经复用方可确认。

## 文档层级

**实体**：文章 Article、书籍 Book、图书馆 Library，链接，文档库。

**手段-目的**：一篇文章内部、文章与文章之间（书籍内）、书籍与书籍之间（图书馆内，也可跨馆）的关系，是三个不同层级的关系。链接混乱的根源，就是把不同层级的关系混在一起处理：先判断一条链接属于哪一层，每一层的建立规则与治理方式各不相同。

**约束**：适用于文档及其集合之间的结构关系；不适用于文档内容本身的组织。

**行动**：想建模或治理文档关系，先分清关系发生在哪一档，再选择对应的处理方式。
