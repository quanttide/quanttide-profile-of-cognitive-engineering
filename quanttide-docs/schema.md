# 图式

图式是可复用、可推理的心智模型：满足某类条件时，借助一组概念可以推出该采取的行动。每条图式须经多个情境复用后方可确认为已验证。

## 治理文档链接

**实体**：树状结构、网状连接、链接、显式约定。

**手段-目的**：文档默认保持树状，链接只有在业务规定明确要求时才建立；由此推出，凡是业务上说不清链接理由的引用都应删除。乱跳的链接会淹没正事，因此判断标准是「能否对这条链接说出业务理由」，而不是「内容上有关联」。

**约束**：只适用于文档之间的引用关系；文档内部的结构层级不适用。

**行动**：想在文档之间建立引用，先说出业务理由；说不出就不建链接，并让 AI 清理掉已有的无理由链接。
