# 图式

图式是可复用、可推理的心智模型。它有两类形态：概念结构型，定义实体与层级，效力来自概念本身清晰；经验归纳型，从多个情境中提炼，须经复用方可确认。

## 文档关系三档层级

**实体**：article、book、library，链接，文档库。

**手段-目的**：文档之间的关系发生在三个不同的档次——article 内部的关系、book 级别的关系、library 级别的关系（含跨库）。由此推出，治理文档关系时先判断关系落在哪一档，每一档的维护与治理方式不同；跨档混用正是链接混乱的来源之一。

**约束**：适用于文档及其集合之间的结构关系；不适用于文档内容本身的组织。

**行动**：想建模或治理文档关系，先分清关系发生在哪一档，再选择对应的处理方式。

## 候选

「链接是业务关系在文档空间的投影」——文档之间的连接对应业务关系的显影，三档层级对应业务关系嵌套的层级，树状默认对应业务的主从结构。该候选尚待澄清与验证，暂不入列。
