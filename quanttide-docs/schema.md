# 图式

图式是可复用、可推理的心智模型。它有两类形态：概念结构型，定义实体与层级，效力来自概念本身清晰；经验归纳型，从多个情境中提炼，须经复用方可确认。

## 文档层级

### 目的

判断一条链接该不该建、链接混乱出在哪时。

### 实体

- **文章 Article**：一篇独立成文的文档，内容自洽，是关系发生的基本单元。
- **书籍 Book**：一组围绕同一主题组织起来的文章，文章之间的关系主要发生在书籍内部。
- **图书馆 Library**：一组书籍的集合，书籍之间的关系发生在这里，也可跨馆发生。
- **关系**：文档之间的关联，按所处层级分为文章内、书籍内、图书馆内（含跨馆）三档。
- **链接**：关系在文档中的具体载体，一条链接对应一条关系。

### 推理

文章内、书籍内、图书馆内（含跨馆）的关系，是三个不同层级的关系。链接混乱的根源，就是把不同层级的关系混在一起处理：先判断一条链接属于哪一层，每一层的建立规则与治理方式各不相同。

### 约束

适用于文档及其集合之间的结构关系；不适用于文档内容本身的组织。

### 行动

想建模或治理文档关系，先分清关系发生在哪一层，再选择对应的处理方式。
