# 情境

## 治理文档结构

### 感知 L1

文档量大且链接容易乱连；历史上腾讯云文档乱跳链接的体验恶劣；AI 参与写作后格式混乱更明显。

### 理解 L2

核心是全局结构管理——文档云要能计算并预警链接混乱之处；可视化关系图不止用于看，还要支撑决策治理。

### 预测 L3

先以树状结构和显式链接约定约束文档关系，再由预警机制识别其中混乱之处，用关系图支撑持续的治理决策，最终以树状优先、链接谨慎为原则建成文档云的结构治理能力，让人访问文档时不再出问题。

## 智能排版文档

### 感知 L1

文档格式（表格、列表、正文）可被解析器解析出具体数字；AI 生成内容格式多且乱。

### 理解 L2

通过对文档格式做定量分析，再用人类阅读体验反向评估，就能得到有效的内容质量指标；文档工程关心的是阅读负担，叙事工程关心的才是 storytelling。

### 预测 L3

格式定量指标成熟后，即可用它判断哪些内容需要优化，并与阅读负担检测融合为文档质量的前置过滤，使定量评估成为文档质量的常规评估手段。
