# 情境

## 治理文档结构

### 感知 L1

文档量大且链接容易乱连；历史上腾讯云文档乱跳链接的体验恶劣；AI 参与写作后格式混乱更明显。

### 理解 L2

核心是全局结构管理——文档云要能计算并预警链接混乱之处；可视化关系图不止用于看，还要支撑决策治理。

### 预测 L3

树状结构 + 显式链接约定 → 预警机制识别混乱点 → 关系图驱动持续治理 → 人访问时不再出问题；以树状优先、链接谨慎为原则建设文档云的结构治理能力。

## 智能排版文档

### 感知 L1

文档格式（表格、列表、正文）可被解析器解析出具体数字；AI 生成内容格式多且乱。

### 理解 L2

格式定量分析 + 阅读体验反评 = 有效的质量指标；文档工程关心阅读负担，叙事工程关心 storytelling。

### 预测 L3

格式定量指标成熟后，即可用它判断哪些内容需要优化，并与阅读负担检测融合为文档质量的前置过滤，使定量评估成为文档质量的常规评估手段。
