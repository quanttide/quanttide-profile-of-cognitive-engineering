# 图式（schema）· 销售

图式 = 可复用、可推理的心智模型。字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 销售边界

- **目的**：区分销售与商务的工作方式时。
- **实体**：销售、商务、具体的人、规则。
- **手段-目的**：对具体的人 → 需要总结说服方法；对规则 → 需要理解市场习惯。
- **约束**：两者不可混用。
- **行动**：针对具体的人总结说服方法。

## 2. 信任链条

- **目的**：选择获客渠道时。
- **实体**：微信社群、小红书、信任链条、熟人社群。
- **手段-目的**：有基础信任链条 → 线索质量高；无信任基础 → 质量低。
- **约束**：信任链条主要依赖熟人已有的社群。
- **行动**：优先通过熟人社群渠道获客。
