# 图式（schema）· 商业

图式 = 可复用、可推理的心智模型。字段直接采用 CWA 抽象层级与活动理论：**目的**（为何激活 · functional purpose）、**实体**（概念与属性 · 本体论）、**手段-目的**（条件→结果 · means-ends）、**约束**（适用/排除 · CWA constraints）、**行动**（意图→行动 · 活动理论）。

> 状态图例：未标注 = 已确认；🔄 进行中；❓ 待验证。来源见文末。

## 1. 商业模式简单化

- **目的**：市场存在客观能力限制、领域存在天然门槛时。
- **实体**：商业模式、市场资源、稀缺资源。
- **手段-目的**：模式过于复杂 → 难以利用市场资源 → 无法规模化。
- **约束**：必须足够简单；需要不断感知市场变化。
- **行动**：用不稀缺的资源加工成稀缺资源。

## 2. 减脂试错 🔄

- **目的**：验证商业模式、筛选策略时。
- **实体**：产品线、试错空间、备选策略。
- **手段-目的**：产品线越多 → 试错空间越大 → 一个跑出来整个系统就能活。
- **约束**：资源匮乏时需看准再下手；与「想清楚再行动」存在张力。
- **行动**：大量抛弃备选但不可行的策略。

## 3. 反直觉收费 ❓

- **目的**：企业付费意愿低、成本负担重时。
- **实体**：企业侧、人才侧、闭环。
- **手段-目的**：企业不愿付费培养 → 从人才侧收费 → 取决于闭环能否形成。
- **约束**：需要源源不断的流量（招聘渠道已验证）；必须明确知道大部分人确实不适合。
- **行动**：以招聘为起点，强化已有学员权重。

## 4. 实证感

- **目的**：评估商业模式是否可行时。
- **实体**：商业模式、实证、AI 质疑。
- **手段-目的**：有实证感 → 模式可跑通；缺乏证据 → 持续怀疑。
- **约束**：经济学专业训练使怀疑成为常态；怀疑驱动寻找证据，也带来认知负担。
- **行动**：吸收 AI 建议，不断寻找证据。
